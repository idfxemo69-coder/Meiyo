FEATURES

What Meiyo does.

Meiyo includes a small set of tools for managing member joins and invites.

01

Welcome messages

Sends a message when someone joins your server.

02

Invite tracking

Tracks invite usage to help identify which link brought in a member.

03

Invite leaderboard

Shows invite counts for members in your server.

04

Automatic roles

Assigns a selected role to new members.

05

Join and leave logs

Records member join and leave events for server tracking.

06

Server settings

Lets server staff configure the supported channels, roles, and messages.

ABOUT THE BOT

Meiyo, in brief.

Meiyo is a personal Discord bot. It is used for welcome messages, invite statistics, member roles, and basic server configuration.

Some features require the relevant Discord permissions to be enabled. Server administrators manage the bot's settings in their own server.

For questions or support, visit the Meiyo Discord server.
