A little help behind the scenes

Meet the bot.

Meiyo is a Discord bot made to take care of a few useful server tasks. It handles welcomes, invite tracking, roles, and member activity so server admins have fewer things to do by hand.

Questions or support?
01 / Features

What Meiyo can do.

01 / GREETINGS

Welcome messages

Send a welcome message when someone joins your server.

02 / INVITES

Invite tracking

Track invite links and see which invites bring new members in.

03 / LEADERBOARD

Invite leaderboard

View invite counts and see who's bringing people along.

04 / ROLES

Automatic roles

Assign a selected role to members when they join.

05 / ACTIVITY

Join & leave logs

Record member joins and departures in a configured channel.

06 / SETTINGS

Server configuration

Set up supported channels, roles, and message preferences.

For server admins: Meiyo needs the relevant Discord permissions for the features you enable. Available settings depend on the permissions and configuration of your server.
